# Moment Timer

집중을 위한 Windows 타이머입니다.

## 다운로드

[최신 버전 설치 파일](https://github.com/liamyoon/moment-timer-releases/releases/latest)을 내려받으세요. Windows 10/11 x64와 WebView2가 필요합니다.

시·분·초 입력, 시간 프리셋, 트레이 타이머, 완료 알람, 최근 기록 5건을 지원합니다. 앱은 새 버전을 확인하고 사용자가 선택하면 서명을 검증한 뒤 설치합니다.

기록은 PC의 앱 로컬 저장소에 보관하며 GitHub 토큰이나 개인정보를 배포 파일에 넣지 않습니다. 이 저장소는 배포 파일 전용입니다.

Windows Authenticode 인증서 서명은 적용되지 않아 SmartScreen에서 알 수 없는 게시자로 표시될 수 있습니다. 업데이트 무결성은 별도 서명으로 검증합니다.

## 포터블 버전 추가

[Windows x64 포터블 EXE 다운로드](https://github.com/liamyoon/moment-timer-releases/releases/download/v1.0.1/Moment.Timer_1.0.1_x64-portable.exe)

설치 없이 실행합니다. Windows 10/11 x64 및 WebView2 Runtime이 필요합니다. 기록은 PC의 앱 저장소에 남으며 EXE와 함께 이동하지 않습니다.

포터블 업데이트는 트레이 메뉴에서 앱을 종료한 후 새 EXE로 교체하세요. 앱의 **설치 후 다시 시작** 버튼은 설치형으로 전환합니다. 자세한 안내는 PORTABLE-README.txt, 해시 검증은 SHA256SUMS-portable.txt를 참조하세요. 기존 설치 파일과 latest.json은 유지했습니다.
